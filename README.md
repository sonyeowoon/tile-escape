# Tile Escape

C와 MiniLibX로 구현한 타일 기반 수집·탈출 게임 학습 프로젝트입니다. 지도 파일을 읽어 화면에 표시하고, 이동과 수집 처리에 앞서 지도의 형식과 도달 가능성을 검사합니다.

## 주요 구현

- 파일에서 타일 지도 로딩 및 형식 검사
- 플레이어 이동과 수집·출구 처리
- 텍스처를 이용한 지도 표시
- DFS로 수집품과 출구의 도달 가능성 검사
- 오류 및 종료 시 자원 정리

## 기술

C, MiniLibX, Linux/X11, DFS, 지도 파싱, Make

## 빌드와 실행

C 컴파일러, Make, X11/Xext 개발 라이브러리와 그래픽 표시 환경이 필요합니다. Makefile은 루트의 `minilibx-linux` 디렉터리를 참조하지만 현재 저장소에는 해당 라이브러리 소스가 포함되어 있지 않습니다. MiniLibX Linux 소스를 그 경로에 먼저 준비해야 합니다.

```sh
make
./so_long maps/map.ber
```

기존 실행 파일 이름 `so_long`을 유지합니다. 지도와 텍스처의 상대 경로를 위해 저장소 루트에서 실행합니다.

## 코드 안내

| 파일 | 내용 |
| --- | --- |
| `dfs.c` | 출구와 수집품 도달 가능성 검사 |
| `check_map.c`, `check_map2.c` | 지도 검사 |
| `init_map.c` | 지도 초기화 |
| `display_map.c` | 지도 표시 |
| `move_player.c` | 플레이어 이동 |

## 범위

지도 파싱·경로 탐색·이벤트 처리를 함께 실습하는 작은 2D 게임입니다. 실제 실행을 위해 외부 그래픽 라이브러리 준비가 필요하며, 이 README 작성 과정에서 빌드·플레이 테스트를 수행한 것은 아닙니다.
